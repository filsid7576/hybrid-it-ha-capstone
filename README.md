# hybrid-it-ha-capstone
# Improving High Availability and Resilience in Hybrid IT Infrastructure

This repository contains the project materials developed for my MSIT 5910 Capstone Project at University of the People.

The project focuses on improving high availability and operational resilience in a representative hybrid IT infrastructure. The main areas considered include infrastructure dependencies, single points of failure, redundancy, monitoring, failover, backup, and disaster recovery.

## Repository Structure

- `docs/` – Project documentation, requirements, reports, and supporting material.
- `design/` – Architecture diagrams and other system design files.
- `source/` – Scripts, configuration examples, and other technical files developed during the project.

## Branching Strategy

The repository uses two main branches:

- `main` – Contains the stable version of the project files.
- `development` – Used for ongoing changes and updates before they are incorporated into the main branch.

## Version Control

Git is used to maintain a history of changes made during the project. Descriptive commit messages are used to identify updates to documentation, architecture, and technical material and to provide traceability throughout the development of the capstone project.

## Project Status

The project is currently under development as part of the MSIT 5910 Capstone Project.
